A fast drop-in for makefun-site 1.0.0: it builds the same static sites, byte for byte, in less CPU time. `solve.js`
is a dependency-free ES module whose `run(input)` returns the output tree makefun-site returns for one generated
site, and `main.ts` answers every case in `/input/cases.json` with it.

## Run it

```sh
node main.ts
```
